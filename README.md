# Модуль «Экспорт РИНЦ XML»

Модуль (плагин) для OJS, позволяющий экспортировать метаданные статей в формате [РИНЦ XML](https://validator.elibrary.ru/Journals/Scheme).

Это версия [оригинального модуля](https://github.com/erikrause/RSCIExportOJSPlugin) с доработками для передачи выпусков в РЦНИ (ИС «Метафора»): в архив выгрузки надёжно попадают обложка и PDF-гранки статей, а после выгрузки показывается отчёт о проблемах. Список изменений — в конце.

## Требования

  - OJS 3.5 (эта версия). Версии модуля для OJS 3.1–3.4 — в ветках [оригинального репозитория](https://github.com/erikrause/RSCIExportOJSPlugin).
  - PHP 8.x

## Установка

Скачайте архив `rsciexport-<версия>.tar.gz` из раздела [Releases](https://github.com/Ph-We/RSCIExportOJSPlugin/releases).

  - **Первая установка:** «Настройки» → «Веб-сайт» → «Модули» → «Загрузить новый модуль».
  - **Обновление** (модуль уже установлен): «Настройки» → «Веб-сайт» → «Модули», у модуля «Экспорт РИНЦ XML» — «Обновить», загрузить архив. Это действие доступно администратору сайта. Настройки модуля сохраняются.

## Использование

Зайдите в «Инструменты» → «Импорт/Экспорт», откройте модуль «Экспорт РИНЦ XML» и настройте его (вкладка «Настройки»). На вкладке «Выпуски» выберите выпуск и нажмите «Экспортировать выпуск». Скачается архив:

  - `Markup_unicode.xml` — метаданные выпуска и статей;
  - `cover.<расширение>` — обложка выпуска (на основном языке журнала);
  - `<страницы>_<язык>.pdf` — полные тексты статей, например `4-33_ru.pdf`; если у статьи не указаны страницы — `<номер статьи в OJS>_<язык>.pdf`.

В системе Articulus в проекте выпуска журнала зайдите во вкладку «Восстановить» и загрузите скачанный архив.

После выгрузки обновите страницу модуля: под кнопкой выгрузки будет **«Отчёт о последней выгрузке»** — что не попало в архив и почему (нет обложки или PDF, файла нет на сервере, PDF не на нужном языке, совпали страницы у двух статей и т. п.). Если проблемы есть, OJS также покажет короткое уведомление.

### Настройки

  - **Идентификатор журнала в РИНЦ** (titleid).
  - **Экспортировать разделы выпуска** — названия разделов (рубрик) журнала перед их статьями.
  - **Тип статьи по аббревиатуре раздела** — если аббревиатура раздела совпадает с типом статьи РИНЦ; иначе тип `RAR` (научная статья).
  - **Полные тексты в архиве** — какие PDF-гранки класть в архив:
    - «На языке статьи» (по умолчанию) — одна PDF на языке статьи;
    - конкретный язык (из языков подачи журнала) — одна PDF на этом языке, а если её нет — на языке статьи;
    - «Все языковые версии» — по одной PDF на каждый язык.

    Если PDF на нужном языке нет, берётся первая PDF по порядку. У каждого полного текста в XML указан его язык (`<file desc="fullText" lang="RUS">`), у статьи — язык статьи (`<langPubl>`). В архив попадают только PDF-гранки с файлом; HTML-гранки и гранки-ссылки пропускаются.

### Выгрузка из командной строки

```
php tools/importExport.php RSCIExportPlugin export <архив.zip> <путь_журнала> issue <ID_выпуска>
```

Отчёт о проблемах печатается в консоль.

### Ограничения
Этот модуль формирует все метаданные для РИНЦ, которые определены в базовой установке OJS 3.

Не формируются:
  - полнотекстовые индексы статей
  - сквозной номер выпуска
  - рецензии статей
  - финансирование статей
  - рубрики статей
  - РИНЦ ID и коды авторов, кроме ORCID

### Обработка аффилиации авторов
При обработке аффилиации авторов можно после наименования организации через запятую указать город и страну, модуль автоматически разделит организацию и адрес на разные атрибуты.
Также можно использовать символ ";" как разделитель между элементами массива, таким образом можно обозначить несколько организаций, причем при указании нескольких одинаковых адресов
сформируется один адрес.

Например, атрибут "организация" в OJS:
 > СурГУ, г. Сургут, Россия; ФГУ ФНЦ НИИСИ РАН, г. Сургут, Россия

сформирует следующие XML-тэги:

``` 
<orgName>СурГУ; ФГУ ФНЦ НИИСИ РАН</orgName>
<address>г. Сургут, Россия</address>
```

## Изменения в версии 0.1.4.1

По сравнению с версией 0.1.4.0 оригинального модуля (подробности и проверка каждого изменения — в [pull request'ах](https://github.com/Ph-We/RSCIExportOJSPlugin/pulls?q=is%3Apr+is%3Amerged) этого репозитория):

  - **Обложка** берётся с диска сервера и называется `cover.<расширение>`. Раньше она скачивалась по веб-ссылке и молча пропадала из архива, если в имени файла были пробелы или кириллица. Выбирается обложка на основном языке журнала (раньше зависело от языка интерфейса того, кто выгружает). (#2)
  - **Полные тексты**: берутся только PDF-гранки с файлом, на языке статьи, и называются `<страницы>_<язык>.pdf`. Раньше бралась первая гранка любого типа под исходным именем файла: в архив попадал HTML вместо PDF, на гранке-ссылке выгрузка падала, а статьи с одинаковыми именами файлов затирали друг друга — статья могла уйти с чужим полным текстом. Имя файла в XML и в архиве теперь всегда совпадает. (#4)
  - **Языковые метки**: `lang` у каждого полного текста и `<langPubl>` у статьи. (#5)
  - **Настройка «Полные тексты в архиве»**: язык гранки или все языковые версии. (#6)
  - **Отчёт о выгрузке** на странице модуля и в консоли; PDF-гранка, чей файл отсутствует на сервере, пропускается, и XML на неё не ссылается. (#7)
  - Исправлено: выгрузка падала при включённом экспорте разделов — две ошибки подряд (#1, #3); статьи без страниц или с одинаковой первой страницей пропадали из XML (#8).
